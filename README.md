# BandSOS Coastal Flood Forecasting Platform

Experimented on the Bengal Delta in Bangladesh, BanDSOS aims to establish a pre-operational service for forecasting
cyclonic flooding and the associated societal risk. This service will have two components: a forecast of the coastal
flooding hazard in real time that uses a state-of-the-art coupled hydrodynamic-wave modeling platform and a coupling
of this forecast with a mapping of the vulnerability of the exposed areas. The project is a collaboration with
Bangladesh Water Development Board (BWDB) - the government engineering organization of Bangladesh that manages the water
resource infrastructure and tasked with providing the flood forecasting to the vast community of Bangladesh.

This repository contains the codebase to build a BandSOS system and examples of script for forecasting. Please consult the
[full documentation](https://jamal919.github.io/bandsos-platform) on how to set up the BandSOS platform and
the [BandSOS/BWDB Portal](https://bandsos.github.io) for the forecasts produced by BandSOS for the Bay of Bengal.
